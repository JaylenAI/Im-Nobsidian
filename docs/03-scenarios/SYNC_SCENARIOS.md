# 동기화 시나리오

> 작성일: 2026-05-08
> 상태: draft
> Phase 1에서 작성 예정

## 정상 시나리오

- [ ] 최초 동기화 (빈 Notion → 전체 push)
- [ ] 로컬 파일 수정 → push
- [ ] Notion 페이지 수정 → pull
- [ ] 새 로컬 파일 생성 → Notion 페이지 생성
- [ ] 새 Notion 페이지 생성 → 로컬 파일 생성
- [ ] 로컬 파일 삭제 → Notion 페이지 삭제 (or 보존)
- [ ] 폴더 이동 → Notion 페이지 부모 변경

## 충돌 시나리오

- [ ] 양쪽 동시 편집 (다른 부분)
- [ ] 양쪽 동시 편집 (같은 부분)
- [ ] 한쪽 삭제 + 다른쪽 편집

## 에러 시나리오

- [ ] Notion API 오류 (rate limit, 500, 네트워크)
- [ ] 로컬 파일 권한 오류
- [ ] 큰 파일 (20,000+ 블록)
- [ ] 잘못된 마크다운 형식
