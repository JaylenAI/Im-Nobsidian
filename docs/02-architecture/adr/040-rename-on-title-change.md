# ADR-040: Notion 에서 바꾼 제목으로 노트 이름을 바꾸고 링크를 고친다

> 상태: 승인
> 결정일: 2026-10-26

## 맥락

- Notion 에서 페이지 제목을 바꾸면 pull 은 새 제목을 frontmatter `title:` 에 적고 파일 이름은 둔다(D2). 볼트와 Notion 의
  이름이 갈라진 채 남는다
- ADR-039 로 Notion 에서 옮긴 노트를 볼트에서 옮기게 됐는데, 그 노트를 경로로 적은 링크(`[[A/c]]`)는 끊겼다. 동기화는
  `vault.rename`(플러그인) · 파일 시스템(CLI)으로 옮기므로 Obsidian 의 「링크 자동 갱신」 이 돌지 않는다
- 파일 이름을 바꾸면 `[[옛 이름]]` 링크가 모두 끊긴다 — 이름을 바꾸려면 링크 고치기가 먼저 있어야 한다

## 선택지

| 안                                            | 장점                    | 단점                                                          |
| --------------------------------------------- | ----------------------- | ------------------------------------------------------------- |
| A. 늘 이름을 바꾼다                           | Notion 과 이름이 같다   | 지금까지의 동작이 바뀐다. 파일 이름을 따로 정한 사람이 놀란다 |
| **B. 선택으로 둔다(기본 꺼짐) + 링크 고치기** | 지금 동작 그대로가 기본 | 켜야만 따라간다                                               |
| C. 그대로 둔다                                | 바뀌는 것 없음          | 이름이 갈라진다. 옮긴 노트의 경로 링크가 끊긴다               |

## 결정

**B.** 링크 고치기는 선택과 상관없이 옮긴 노트에도 쓴다.

1. **언제 바꾸나** (`retitledInNotion`) — 지난 사본의 제목이 파일 이름을 따랐고(따로 정한 `title:` 이 없었다), 볼트에서
   제목을 고치지 않았고, Notion 의 새 제목이 파일 이름과 다를 때. 볼트에서 옮긴 것을 아직 올리지 않았으면 볼트가 먼저다
2. **새 이름** — 새 페이지를 받을 때와 같은 규칙(`pagePathCandidates`): 자연 이름, 차 있으면 `(id8)` · `(id16)` · `(id32)`
3. **옮길 단위** — ADR-039 와 같다(`NoteRelocator` 로 묶었다). 노트와 옆의 자식 폴더, 폴더 노트는 노트 이름과 폴더,
   폴더로 추적하는 페이지는 폴더. 받기 전에 차례로 돈다 — 받기는 여럿을 함께 쓴다
4. **DB 행** — 행을 받을 때 바꾼다(`DatabaseSyncer` 의 재배치 길). 행의 하위 페이지 폴더도 옮기고 보존 마커 경로도 옮긴다.
   하위 폴더를 옮길 수 없으면 이름을 바꾸지 않는다
5. **링크 고치기** (`rewriteLinks` · `LinkUpdater`) — pull 끝에서 옮긴 차례를 거꾸로 되짚어 옛 볼트를 만들고, 링크마다
   Obsidian 처럼 대상을 푼다(이름 · 경로 · `./` `../` 상대 경로, 같은 이름이 여럿이면 링크를 쓴 노트의 폴더 것, 그것도
   없으면 두지 않는다). 고친 링크는 원래 꼴을 따른다. `#제목` · `|별칭` · `\|` · 코드 안은 둔다
6. **다음 push** — 동기화된 노트(지난 사본 그대로)는 고친 글을 해시 · 사본 · stat 으로 적는다. Notion 의 링크는 페이지를
   가리켜 그대로이므로 다시 올리지 않는다. 올리지 않은 편집이 있던 노트는 그 편집과 함께 올라간다
7. **알림** — CLI `(renamed)` · `(would rename)` 줄, 「links updated in N notes」, JSON `renamed` · `relinked`. 플러그인
   알림의 「이름 변경 N」 · 「링크 고침 N」

## 트레이드오프

- 제목만 바꾼 페이지는 수정 시각이 바뀌어 증분 pull 이 바로 본다(옮긴 것과 다르다)
- 링크 고치기는 볼트의 노트를 모두 읽는다 — 옮긴 것이 있을 때만
- 이 연결이 보는 노트만 고친다 — 경로 패턴이 뺀 노트 · 다른 연결 폴더의 노트의 링크는 끊긴 채 남는다
- 이름 꼴 링크(`[[이름]]`)는 이름이 그대로면 고칠 것이 없다(Notion 에서 옮긴 경우)

## 영향

- `sync.renameOnTitleChange`(config) · 플러그인 설정 `renameOnTitleChange`
- `PullResult.moved[].renamed` · `PullResult.relinked`
- 새 모듈 `utils/link-rewrite.ts` · `sync/link-updater.ts` · `sync/remote-renames.ts` · `sync/note-relocation.ts`
