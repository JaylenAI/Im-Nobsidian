# ADR-034: 블록 폴백 pull 은 블록을 NFM 으로 옮겨 Markdown API 경로와 같은 변환을 거친다

> 상태: 승인
> 결정일: 2026-10-12
> 바꾼 것: 블록 폴백 pull 의 notion-to-md 변환 — 따로 정한 ADR 은 없었다

## 맥락

pull 은 Markdown API 로 본문을 받는다. 받지 못하면(잘린 블록이 상한보다 많음 · 오류 · `preferMarkdownApi: false`)
블록 API 로 받는다. 블록으로 받은 본문은 notion-to-md 와 우리 변환기로 볼트 마크다운을 바로 만들었다.

같은 페이지가 받는 길에 따라 다른 노트가 됐다. 코퍼스 10장을 두 길로 받아 견주니 10장이 모두 달랐다(2026-10-12).

- 토글 블록을 통째로 버렸다. 콜아웃의 자식 · 접는 제목의 표시와 자식이 빠졌다.
- 글자 색 · 밑줄 · 표 표시 · 칼럼 비율 · 콜아웃 아이콘과 색이 사라졌다.
- 표 칸의 `|` 가 escape 없이 나와 표가 깨졌다. 목록 들여쓰기가 탭이 아닌 공백 넷이었다.

그 노트를 Markdown API 로 push 하면 본문을 통째로 바꾸므로, 빠진 만큼 Notion 에서 지워진다. 탐침 페이지에서 토글과
그 안의 북마크가 실제로 지워졌다.

notion-to-md 의 변환기를 하나씩 고치는 길은 끝이 없다. 두 길이 같은 규칙을 따로 구현하는 한 다시 갈라진다.

## 실측 — Notion 이 내보내는 NFM

블록 API 로 만든 탐침 페이지 13장의 블록 트리와 같은 페이지의 Markdown API export 를 짝으로 받았다
(`tests/fixtures/nfm/`). 규칙은 `converter/blocks-to-nfm.ts` 머리말에 적었다. 그중 짐작과 달랐던 것:

- 블록마다 한 줄, 빈 줄이 없다. 인용 · 목록의 자식도 `>` 없이 탭으로 들여쓴다.
- 코드 블록의 몸통 줄과 표의 줄은 들여쓰지 않는다. 블록 수식은 식의 첫 줄만 들여쓴다.
- 서식 끝의 공백은 서식 기호 안에 둔다(`**굵게 **`). 서식이 같은 이웃 조각은 하나로 붙는다.
- 인라인 코드 · 링크 주소 · 수식 안의 글자는 escape 하지 않는다. 줄바꿈은 인라인 코드 안에서도 `<br>` 이다.
- 동기화 참조 블록의 주소는 원본이 든 페이지가 아니라 받는 페이지에 원본 블록 id 를 붙인다.

## 결정

블록 트리를 Notion 의 export 와 같은 NFM 으로 옮긴 뒤(`blocksToNfm`), Markdown API 로 받은 본문과 같은 변환
(`notionBodyToObsidian`)에 넘긴다(`pageBlocksToObsidian`).

- 블록 트리는 자식까지 읽는다(`NotionClient.getBlockTree`). 자식 페이지 · DB 는 열지 않는다. 하나라도 읽지 못하면
  던진다 — 빠진 채로 쓰면 다음 push 가 그 블록을 지운다.
- 코드 블록의 글 · 북마크의 주소와 캡션은 트리에 이미 있어 다시 묻지 않는다.
- 옮긴 NFM 은 압축형이다. Markdown API 경로처럼 블록 사이 간격을 다시 맞춘다. 원격 지문은 남기지 않는다 — 지문은
  Markdown API 본문끼리만 견준다.

받아들이는 기준은 둘이다. 짝 13장에서 옮긴 NFM 이 export 와 글자까지 같다(블록 API 가 주지 않는 것은 빼고 견준다).
실 Notion 에서 두 길로 받은 노트가 같다.

## 블록 API 가 주지 않아 옮기지 못하는 것

| 무엇                                  | 결과                                                                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 표의 열 너비 · 행 색                  | 볼트의 표 마커가 빠진다 — push 하면 Notion 의 열 너비 · 행 색이 기본값이 된다                                             |
| 콜아웃 첫 줄 아래에 단 자식           | 블록 API 의 자식 목록에 없다. Markdown API 로만 만들 수 있는 모양이다                                                     |
| 정각이 아닌 지역 시간대의 이름        | `Asia/Calcutta` 09:00 이 `UTC` 03:30 이 된다 — 같은 순간이다                                                              |
| 인라인 DB 의 data source · 표시 방식  | 볼트 모양에는 쓰이지 않는다                                                                                               |
| 멘션한 페이지가 자식이 아닐 때의 모양 | Notion 은 제목 없는 `mention-page`(DB 도), 우리는 제목과 종류를 싣는다 — 볼트에서 같은 위키링크가 된다(DB 멘션은 DB 마커) |

## 트레이드오프

- Notion 의 export 규칙을 우리가 다시 구현한다. Notion 이 export 모양을 바꾸면 폴백만 옛 모양을 낸다. 짝 픽스처가
  그때 다시 잴 근거다.
- notion-to-md 의 pull 쪽(`BlockConverter.notionBlocksToMarkdown` 과 그 변환기들)은 제품 경로에서 쓰이지 않게 됐다.
  지우는 것은 별도 작업이다 — 오프라인 왕복 시험들이 아직 그것을 쓴다.
