# ADR-056: 노트가 품은 폴더의 파일 — 그 노트의 페이지에 «📁 이름» 으로 올리고, 받을 때 노트에서 뗀다

> 상태: 승인
> 결정일: 2026-11-02
> 「Notion API 한계를 빼고 모두 동기화」 계획의 P16 · ADR-054 의 남은 한계를 없앤다

## 맥락

ADR-054 는 폴더 첨부를 **폴더 레코드의 페이지에만** 올렸다. 폴더 노트가 있는 폴더(`X/X.md` 옆 `X/data.csv`)와 노트 이름의
폴더(`N.md` 옆 `N/sheet.csv`)의 파일은 경고만 내고 올리지 않았다 — 그 폴더의 Notion 페이지는 노트의 페이지이고, 노트를 push 하면
본문을 통째로 바꿔(replace_content) 덧붙인 파일 블록이 지워지기 때문이다. 받는 쪽도 그 페이지의 파일을 노트의 임베드로 받았다.

고치는 중 하나를 더 찾았다(ADR-054 부터): **같은 크기로 고친 폴더 첨부를 올리지 않았다** — 크기가 같으면 바뀌지 않았다고 봤다.

## 결정

1. **노트의 페이지 끝에 올린다** — 폴더 노트는 그 폴더, 노트(`N.md`)는 같은 이름의 폴더(`N/`)를 품는다. DB 행 · DB 폴더 · 볼트 맨
   위의 파일은 예전처럼 경고로 알린다
2. **캡션에 표시를 단다**(`📁 data.csv`) — 노트 임베드와 블록 모양이 같다. 0.4.0 전의 push 는 노트 임베드의 캡션에 이름을 적었으므로
   «캡션 = 이름» 은 노트의 것일 수 있다. 폴더 페이지에서는 표시가 없어도(0.18 · 0.19 가 올린 것) 예전처럼 받는다
3. **받을 때 노트에서 뗀다** — 맨 바깥 줄 하나가 통째로 파일 하나이고, 표시를 단 캡션이거나 이 페이지의 폴더 첨부로 적어 둔
   파일 id(`folder_files:<페이지>`)이면 노트가 아니라 그 폴더의 파일로 받는다. **끝자리만 보지 않는다** — Notion 에서 페이지 맨
   아래에 글을 쓰면 그 글이 파일 뒤에 붙는다. 들여 쓴 줄(토글 · 목록의 자식) · 코드 펜스 안 · 로컬 노트가 임베드한 이름 · 이 볼트가
   노트 첨부로 올린 파일은 노트의 것으로 둔다
4. **노트를 push 할 때 그 페이지의 폴더 첨부 줄을 받은 그대로 끝에 되싣는다** — 받은 URL 을 replace_content 에 다시 실으면 Notion 이
   그 블록을 둔다(2026-10-12 실측 · `keepUploadedMedia` 와 같다). 적어 둔 폴더 첨부가 없으면 읽지 않는다. 읽지 못하면 push 를
   멈춘다 — 모르고 바꾸면 파일 블록이 지워진다
5. **파일을 올리고 지운 것은 노트를 바꾼 것으로 보지 않는다** — 올리기 전 그 노트 페이지가 지난 동기화 그대로였으면, 올린 뒤 관측을
   새로 적는다. 아니면 다음 push 가 «Notion 에서도 바뀐 페이지» 로 멈췄다
6. **노트 페이지의 블록은 파일 id 로만 지운다** — 노트가 같은 이름의 파일을 임베드했을 수 있다. 폴더 페이지는 예전처럼 이름으로
7. **블록 방식(Markdown API 를 쓰지 않을 때)** 은 본문 블록을 모두 지우고 새로 붙이므로 폴더 첨부 기록을 놓는다 — 이어지는 첨부
   push 가 다시 올린다
8. **같은 크기 수정** — 올리거나 받은 때의 크기 · 수정 시각을 적어 두고(sync_metadata `folder_file_stamps:<페이지>` — 스키마는
   그대로), 다르면 크기 → 내용(해시)으로 견준다. 같으면 지금 표를 적어 다음에는 읽지 않는다

## 결과

- 폴더 노트 · 노트 이름의 폴더에 둔 파일이 두 볼트에서 왕복한다 — 고치기(같은 크기 포함) · 지우기 · Notion 에서 맨 아래에 쓴 글 ·
  다른 볼트의 노트 고침 뒤에도. 두 번째 push · pull 은 변화 0
- 업그레이드한 볼트의 첫 push 는 그동안 경고로 남던 폴더 노트 옆 파일을 올린다

## 남은 한계

- 블록 방식으로 노트를 push 하면 그 페이지의 폴더 첨부를 다시 올린다(Notion 파일 id 가 바뀐다)
- Notion 에서 폴더 첨부 블록을 토글 · 목록 안으로 옮기면 노트의 임베드가 된다
- 하위가 없는 노트 페이지는 다른 볼트에 노트(`Z.md`)로 받는다 — 파일은 같은 이름의 폴더(`Z/`)에 든다(Notion 모델)
