# ADR-048: 그 밖의 구조 — 이름 · 옵션 · 보기 · 링크드 뷰 · 링크를 양쪽으로

> 상태: 승인
> 결정일: 2026-10-30
> 「Notion API 한계를 빼고 모두 동기화」 계획의 P6. ADR-038(연결 폴더) · ADR-040(제목으로 이름 바꾸기) · ADR-045(스키마 양방향) ·
> ADR-046(보기 양방향) · ADR-047(페이지 ↔ DB 이동)이 남긴 것을 메운다

## 맥락

P3 ~ P5 가 남긴 한계:

- status · `pull --dry-run` 은 페이지의 이름 바꾸기만 보였다. 행 이름은 DB 받기가 바꿔서 미리 보이지 않았다
- CLI 는 이름 바꾸기 이벤트가 없어, 이름과 내용을 함께 바꾼 노트를 새 페이지로 만들고 옛 페이지를 남겼다
- Notion 에서 DB 이름을 바꾸면 `.base` · 사이드카 이름만 바뀌고 폴더는 옛 이름으로 남았다(ADR-047 트레이드오프)
- 사이드카에서 선택 옵션 이름을 바꾸면 옛 옵션을 지우고 새로 만들어 그 값의 행이 빈 값이 됐다(ADR-045)
- 동기화가 폴더를 옮기면 사용자가 만든 `.base` 의 폴더 필터는 고치지 않아 빈 표가 됐다(ADR-047)
- 볼트에서 더하거나 지운 `.base` 보기는 Notion 에 만들지 · 지우지 않았다(ADR-046)
- 다른 페이지에 넣은 링크드 뷰를 원본 DB 의 `.base` 로 몰아 넣어, 링크드 뷰가 고른 보기 · 필터 · 정렬이 볼트에 오지 않았다
- 동기화가 노트를 옮기면 그 연결이 보는 노트의 링크만 고쳤다. Obsidian 은 링크를 볼트 전체에서 찾으므로 다른 연결 폴더 ·
  경로 패턴이 뺀 노트의 링크가 끊겼다(ADR-038)
- `[[노트#제목]]` · `[[노트#^블록]]` · `[[#제목]]` 은 Notion 에 글자로 남아 눌러도 아무 데도 가지 않았다

## 실측(2026-10-30, Notion-Version 2025-09-03 · 탐침 `__p6_structure_20261030__`)

- 선택 옵션: `PATCH` 에 옵션 id + 새 이름을 주면 200 인데 이름은 그대로고 색만 바뀐다(2025-09-03 · 2026-03-11 둘 다)
- 보기 이름만 바꾸면 페이지 · DB 의 `last_edited_time` 이 그대로다
- API 로 블록을 지우면(링크드 뷰 블록 포함) 부모 페이지의 `last_edited_time` 이 그대로다
- 블록 링크: Notion 은 `https://www.notion.so/<페이지>#<블록>` 을 받아 `https://app.notion.com/p/<페이지>#<블록>`(줄인 id)으로
  돌려주고 쿼리는 버린다. 링크 글자의 `>` · `^` 는 마크다운에서 `\>` · `\^` 로 돌아온다
- 페이지 멘션에 블록을 붙이면(`<mention-page url="…#<블록>">`) 페이지 id 자리에 블록 id 가 들어가 깨진다
- 본문을 통째로 바꿔도(`replace_content`) 바뀌지 않은 블록과 글만 고친 블록의 id 는 남는다
- `last_edited_time` 은 분 단위다 — 같은 봇 토큰이 같은 분에 고친 것은 바뀌지 않은 것으로 읽힌다(ADR-017 한계, 탐침 중에 다시 봄)

## 결정

1. **행 이름 미리 보기** — 받기 · status · dry-run 이 같은 판정(`retitledRowTarget`)으로 Notion 에서 바꾼 행 제목의 새 파일
   이름을 정한다(`sync.renameOnTitleChange`)
2. **이름과 내용을 함께 바꾼 노트 짝짓기(CLI)** — 사라진 노트와 새 노트가 같은 폴더거나 같은 파일 이름이면서 본문 겹침(낱말 두
   개씩 Dice)이 0.6 이상이면 같은 페이지로 잇는다. 겹침이 같은 후보가 둘이면 잇지 않는다 — 잘못 이으면 다른 노트를 덮는다
3. **Notion DB 이름 → 폴더 이름** — 폴더 이름이 지난번에 받은 DB 이름을 따를 때만 바꾼다(사용자가 지은 이름은 둔다).
   `.base` 이름이 바뀌면 그것을 넣은 임베드도 고친다(설정을 켜지 않아도)
4. **선택 옵션 이름 바꾸기** — 사이드카에서 같은 자리의 옵션 이름이 바뀌면, 새 옵션을 더하고 그 값의 행을 옮긴 뒤 옛 옵션을
   지운다. API 가 이름을 바꾸지 못하므로(실측) 이 길밖에 없다
5. **사용자가 만든 `.base` 의 폴더 필터는 묻는다** — 무엇을 보려는 필터인지 모르므로 고치지 않고 물을 것으로 남긴다
   (`user_base_filter_fixes`). CLI 는 pull · push · sync 끝에 묻고(`--yes` 는 고침 · 터미널이 아니면 알리기만), 플러그인은 작업이
   끝난 뒤 창으로 묻는다. 쓴 꼴(`file.inFolder` · `file.folder ==`) 그대로 고치고, 두기를 고르면 다시 묻지 않는다
6. **볼트에서 더한 · 지운 보기 → Notion** — 표 · 카드(갤러리) · 목록을 만들고, 만들면 바로 기록해 다음 push 가 또 만들지 않는다.
   지운 보기는 Notion 에서도 지운다. 그 사이 Notion 에서 고친 보기, 보기를 모두 지운 `.base` 는 지우지 않는다. 보기마다 나머지
   지문(`rest` · `docRest`)을 기록해 더하고 지운 뒤에도 다 올렸는지 가른다
7. **링크드 뷰는 자기 `.base`** — 원본 DB 폴더에 「원본 제목 - 첫 보기 이름」 으로 써서 그 보기의 이름 · 필터 · 정렬을 따로 가진다.
   노트는 그 `.base` 를 넣고, push 는 그 임베드를 같은 링크드 뷰 컨테이너 블록으로 되돌린다. Notion 에서 지운 링크드 뷰는 `.base` 를
   치우고 그것을 넣은 줄을 뺀다 — 수정 시각이 그대로라(실측) 다시 받지 않으면 깨진 임베드가 남는다
8. **다른 연결의 노트에서도 링크 고치기** — CLI · 플러그인이 볼트 전체(`OutsideVault` — 볼트 맨 위 기준 VaultFS + 연결 폴더)를
   넘기면, 이 연결이 보지 않는 노트도 볼트 맨 위 기준으로 견주어 고친다. 그 노트는 맡은 연결이 바뀐 노트로 올린다.
   연결 폴더가 볼트 맨 위이고 경로 패턴 · 무시 파일 · 안쪽 연결이 없으면 넘기지 않는다(볼 노트가 없다)
9. **제목 · 블록 링크 ↔ Notion 블록 링크**
   - push: 대상 페이지의 맨 위 블록을 읽어(`fetchAllChildren`) 제목 글자(Obsidian 이 빼는 `# | ^ : % [ ] \` 를 빼고) · 글 끝의
     `^블록id` 가 맞는 블록을 찾는다. `가#나` 는 Obsidian 처럼 앞 제목부터 차례로 찾는다. 글자 링크
     `[노트 > 제목](https://www.notion.so/<페이지>#<블록>)` 으로 보낸다 — 멘션은 깨진다(실측). 별칭이 있으면 별칭을 글자로
   - pull: 볼트에 있는 페이지로 가는 블록 링크는 블록을 읽어(`getBlock`) 제목 · `^블록id` 로 되돌린다. 링크 글자가 Obsidian 이
     보이는 글자면 그 글자에서 노트를 적은 꼴(경로)과 위 제목들을 되살려 보낸 노트와 같게 받고, 아니면 글자를 별칭으로 둔다.
     같은 pull 에서 뒤에 받은 페이지로 가는 링크는 pull 끝의 링크 패스가 고친다
   - 못 찾은 제목 · 읽지 못한 페이지는 예전처럼 글로 둔다(push) · Notion 링크로 둔다(pull)

## 트레이드오프

- 맨 위 블록만 본다 — 콜아웃 · 토글 · 목록 자식 속 제목 · 블록 id 로 가는 링크는 글로 남는다. 페이지마다 블록 트리를 모두
  읽으면 요청이 크게 는다
- 같은 push 에서 새로 만든 제목 · 새 노트의 자기 제목으로 가는 링크는 그 push 에서는 글로 가고, 노트를 다음에 고쳐 올릴 때 링크가
  된다 — 블록 id 는 올린 뒤에야 생긴다
- 짝짓기는 CLI 만 — 플러그인은 Obsidian 의 이름 바꾸기 이벤트를 받는다. 겹침 0.6 미만으로 크게 고친 노트는 새 페이지가 된다
- 옵션 이름 바꾸기는 옵션 id 가 바뀐다 — Notion 의 다른 곳(수식 · 자동화)이 옛 옵션을 가리켰으면 끊긴다
- 링크드 뷰 편집은 그 원본 DB 를 받는 pull · 전체 대조에서만 볼트에 온다(보기 이름 바꾸기는 수정 시각을 바꾸지 않는다).
  예전 pull 이 원본 `.base` 를 넣은 노트는 다음에 그 페이지를 받을 때까지 원본 `.base` 를 가리킨다
- 같은 봇 토큰이 같은 분에 고친 것은 놓칠 수 있다(ADR-017) — 사람이 고친 것 · 다른 분의 것은 받는다
