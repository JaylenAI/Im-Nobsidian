## v0.1.5 — Pull 변환 버그 수정 + E2E 검증 완료 (Current)

Im-Nobsidian v0.1.5는 Pull 시 콜아웃/테이블/수식/첨자/날짜 변환 버그 5건을 수정하고,
7개 파일 13종 포맷 + 실전형 3파일로 E2E 라운드트립 검증을 완료했습니다.
경쟁사 분석 결과 양방향 콘텐츠 동기화 도구는 시장에 전무하며, 오픈소스 배포 준비 95% 완료.

### 핵심 기능

| 기능                     | 상태         | 비고                              |
| ------------------------ | ------------ | --------------------------------- |

| Sync (양방향)            | ✅ 완료      | Pull → Push 순차 실행             |
| 충돌 감지 + 해결         | ✅ 완료      | 4가지 전략 + 실제 원격 내용 비교  |

### v0.1.1에서 수정된 버그

| 수정 항목                       | 증상                                 | 원인                                       | 해결                                 |
| ------------------------------- | ------------------------------------ | ------------------------------------------ | ------------------------------------ |
| `resolveParentPath()` 재귀 해석 | Pull 시 폴더가 1단계만 해석 → 평탄화 | 부모 경로를 1-depth만 조회                 | 재귀적 경로 해석으로 깊은 중첩 지원  |
| `pullCreate()` 폴더 레코드      | UNIQUE 제약 조건 충돌 (7건)          | 같은 parentPageId를 notionPageId로 사용    | 불필요한 폴더 레코드 생성 제거       |
| `isRetryable()` 확장            | 타임아웃/네트워크 에러 시 크래시     | timeout/ECONNRESET/ETIMEDOUT 미처리        | 재시도 대상 에러 코드 추가           |
| `detectLocalChanges()`          | 폴더 레코드 잘못된 삭제 감지         | folder-note/folder-only를 일반 파일로 취급 | fileType 체크로 폴더 레코드 스킵     |
| `ensureFolderPage()`            | 폴더-노트 중복 생성                  | 기존 폴더-노트 레코드 미확인               | StateDB에서 기존 레코드 확인 후 생성 |

### v0.1.5에서 수정된 버그

| 수정 항목               | 증상                           | 원인                                                | 해결                         |
| ----------------------- | ------------------------------ | --------------------------------------------------- | ---------------------------- | ------------------------------------- | ----------------------- |
| `<callout>` 태그 미처리 | Pull 시 콜아웃 소실            | Notion API가 `<callout>` 반환, `::: callout`만 처리 | 양쪽 형식 모두 지원          |
| 미디어 태그 들여쓰기    | 리스트 내 미디어 변환 실패     | Notion이 `\t<pdf>` 형태로 반환                      | 선행 공백 정규식 허용        |
| 인라인 수식 이스케이프  | `$E = mc^2$` → `\$E = mc\^2\$` | Notion이 `$`, `^` 이스케이프                        | 이스케이프 복원 로직 추가    |
| 첨자 이스케이프         | `H~2~O` → `H\~2\~O`            | Notion이 `~`, `^` 이스케이프                        | `unescapeNotionChars()` 추가 |
| 테이블 정렬 행 중복     | `                              | ---                                                 | ` 행 2번 출력                | Notion이 정렬 행을 데이터 행으로 저장 | `isAlignmentRow()` 필터 |
| Date 객체 정규화 우회   | 프론트매터 날짜 깨짐           | `gray-matter`가 Date 객체로 변환                    | `Date` 인스턴스 처리 추가    |
