## `fix/roundtrip-escapes` — Notion 이 Obsidian 과 다르게 읽던 수식 · 기울임

탐침 페이지(`__reffix_root__` 아래)에 Markdown API 로 줄마다 보내고 블록의 rich text 로 읽었다.

| 보낸 글                       | Notion 이 읽은 것                                             | 고친 뒤 보내는 글       |
| ----------------------------- | ------------------------------------------------------------- | ----------------------- |
| `w$^9$가`                     | 글 `$^9$`                                                     | ``w$`^9`$가`` → 수식    |
| `앞 $x^2$ 뒤`                 | 수식                                                          | 그대로                  |
| `*기울 \* 임*`                | 기울임 `기울 \` + 글 ` 임*`                                   | `_기울 \* 임_` → 기울임 |
| `**굵 \* 게**` · `2 \* 3`     | 바르게 읽음                                                   | 그대로                  |
| `name.py` · `name\.py`        | 둘 다 자동 링크 `[name.py](http://…)`                         | 고치지 않음(아래)       |
| 이미지 캡션 `***w***` · `<b>` | 블록 API 로 달면 `\*` · `\<` 로 내보냄 — 받기가 그대로 되살림 | 고칠 것 없음            |

- 수식: Notion 은 여는 `$` 앞이 글자 · 숫자이거나 닫는 `$` 뒤가 글자면 수식이 아니다. Obsidian 이 수식으로 그리고

- 기울임: `_` 는 낱말 안에서 기울임이 아니어서, 앞뒤가 글자인 기울임과 `_` 가 든 기울임은 그대로 둔다.
- 자동 링크는 받기에서 걷지 않기로 했다. Notion 이 건 링크는 Obsidian 에서도 눌리고, 볼트에 이미 있는 노트는
  `fix/self-pull-churn` 으로 로컬 표기가 남는다. 링크가 낀 굵은 글(`**a **[**x.md**](…)** b**`)도 CommonMark 로는
  끝까지 굵게 그려진다.

라이브: 고친 빌드로 이 경우들을 담은 노트를 새 탐침 루트(`__esc_live_20261023__`)에 올리고 빈 볼트로 받았다 — 수식 2 · 기울임 1 이

## `fix/out-of-scope-mention` — 볼트 밖 페이지 멘션의 이름

Notion 은 페이지 멘션을 `<mention-page url="…"/>` 로, 제목 없이 준다. 받기는 볼트에서 그 페이지를 찾아 `[[제목]]` 으로
쓰고, 못 찾으면(동기화 루트 밖) `[<id>](https://www.notion.so/<id>)` 로 남겼다 — 누르면 열리지만 사람이 읽을 수 없다.

이제 pull 마감의 링크 패스(`resolveNotionLinks`)가 남길 멘션의 페이지 제목을 한 번씩 읽어 링크 글자로 쓴다. 같은 pull
안에서는 페이지마다 한 번만 읽고, 휴지통 · 권한 밖이라 못 읽으면 id 를 쓴다. 제목의 `[ ]` 는 `( )` 로(링크 글자에 쓸 수
없다), 강조 기호(`*` `_` `` ` `` `~` `\`)는 escape 한다.

라이브: 탐침 페이지에 루트 밖 페이지 멘션을 달고 빈 볼트로 받았다 — 고치기 전 빌드 `[<id>](…)`, 고친 빌드 그 페이지의
제목. 시험: `out-of-scope-mention-title.test.ts` 4 (수정 전 실패 2), 옛 기대(id 라벨) 2 를 고침. 전량 게이트 4,042 통과.

push 는 그대로다 — 이 링크를 올리면 Notion 에 멘션이 아닌 이름 달린 링크가 된다(예전에는 id 가 이름이었다).

## `fix/child-link-title` — 파일 이름이 될 수 없는 자식 제목

자식 페이지 `a / b` 의 노트는 `a _ b.md`(`sanitizeFileName`)인데 받기는 자식 태그를 `[[a / b]]` 로 썼다. Obsidian 은
이것을 `a ` 폴더의 ` b` 노트로 읽어 끊긴 링크가 됐고, push 는 그 줄을 자식으로 알아보지 못해 자식을 본문 끝으로 옮겼다.

- 받기: 제목이 파일 이름이 될 수 없으면 `[[notion:<id>|제목]]` 으로 남긴다 — 링크 패스가 `[[a _ b|a / b]]` 로 푼다.
  Notion 이 태그 속 대괄호를 `\[` `\]` 로 주므로 먼저 풀고, 별칭의 대괄호는 괄호로 바꾼다(링크가 첫 `]]` 에서 끊긴다).
- push: 줄 하나를 통째로 차지한 그 자식의 Notion 링크(`[a / b](https://www.notion.so/<id>)` — 별칭 달린 위키링크가
  나가는 모양)를 자식 자리로 본다.

라이브: 탐침 노트 아래에 `a / b [x]` 자식을 만들고 빈 볼트로 받음 → `[[a _ b _x_|a / b (x)]]` · 노트 끝에 문단을 더해
push → Notion 에서 자식이 제자리(자식 1) · 다시 받기 0. 시험: `child-link-unsafe-title.test.ts` 5 (수정 전 실패 3).
전량 게이트 4,047 통과.

남은 것: 볼트 밖 멘션을 push 하면 Notion 에 이름 달린 링크가 되고, Notion 은 링크 글자의 `_` 를 escape 하지 않고 돌려준다
— 그 뒤 받은 노트에서 `__제목__` 이 굵게 보일 수 있다.

## `fix/roundtrip-notation` — 새로 받은 볼트의 표기 · 글 백슬래시 손실

라이브(`pages.create({ markdown })` → `retrieveMarkdown`)로 Notion markdown 의 규칙을 다시 쟀다.

| 볼트에 쓴 것              | Notion 에 남는 것 / 돌려주는 것 |
| ------------------------- | ------------------------------- |
| `C:\Users\me`             | `C:Usersme` — **지운다**        |
| `a \ b` · `x\y` · `\한글` | `a  b` · `xy` · `한글`          |
| 줄 끝 `끝\`               | `끝\\` (글로 둔다)              |
| 글 백틱 `` ` ``           | `` \` ``                        |
| 캡션 `***별칭***`         | `\*\*\*별칭\*\*\*`              |
| 콜아웃 안 두 문단         | 블록 사이 빈 줄 없이            |

- push 맨 끝(`sendLiteralBackslashes`): 지워질 `\` 를 `\\` 로. 코드 · 수식 · 링크 주소 · 태그 안은 그대로.
- pull(`receiveLiteralBackslashes` · `receiveLoneBackticks`): push 가 보낸 모양만 되돌린다. `\\*` 처럼 풀면 뒤 글자가
  escape 되는 것, 풀면 인라인 코드가 생기는 백틱은 둔다.
- 별칭(`toWikilinkAlias`): 캡션의 escape 를 푼다.
- 콜아웃(`spaceCalloutBody`): 받기 직전 로컬 노트가 없을 때 콜아웃 본문 블록 사이에 빈 `>` 를 둔다. 들여쓴 줄은 앞 블록에
  그대로 붙이고 탭을 펴지 않는다 — 콜아웃 안 목록의 탭은 push 가 자식 깊이로 읽는다(M3). 문단 + 자식 코드를 붙여 쓰든
  띄워 쓰든 Notion 구조는 같다(라이브 `tree.mjs`: callout → paragraph · code).

라이브(탐침 아래 5 노트, 새 빌드): push 5 → 새 볼트 pull 5 → 다시 pull 0 → push --dry-run 0. 새 볼트의 차이는 셋뿐이다.

1. `C:\\Users`(볼트에서 escape 쌍으로 쓴 것) → `C:\Users` — 그리는 것은 같다. Notion 은 둘을 구분해 담지 않는다.
2. 문장 속 임베드는 Notion 에서 블록이 되므로 따로 선다(API 한계). 별칭은 이제 그대로다.
3. 첨부 이름이 `attachments/<노트>-<해시>.png` 가 된다 — 다음 단계에서 본다.

이미 손실된 채 Notion 에 올라간 글은 노트를 고쳐 다시 올리기 전까지 그대로다(릴리스 노트에 적는다).

시험: `literal-escapes.test.ts` 36. 옛 기대 4 를 고침(콜아웃 경계 2 — 새 볼트는 띄운다, 정규식 `\\s` → `\s`, 압축형
export 의 콜아웃 경계). 전량 게이트 4,083 통과.
