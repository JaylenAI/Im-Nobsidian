### 빈 목록 항목 (실측 `__emptyli__` · `__emptyli2__`)

Notion 은 빈 글머리(`-`) · 빈 번호(`2.`)를 그대로 둔다. `-` 아래 들인 `x.` 는 빈 글머리의 자식 문단이 된다. 받기의 목록
판정 정규식 넷이 표지 뒤에 공백을 요구해 빈 항목을 목록으로 보지 않았다. 표지 뒤가 줄 끝이어도 목록이다.

### 위키링크 안 서식 글자 (실측 `__wikiesc__` · `__wikiesc2__`)

| 보낸 것               | Notion                        |
| --------------------- | ----------------------------- |
| `[[가 _a_ (1)\|…]]`   | 기울임 — `*a*` 로 돌려준다    |
| `\_a\_`               | 글자 — `_a_` 로 돌려준다      |
| `*b*` · `` `b` ``     | 기울임 · 코드                 |
| `\*b\*`               | 글자 — `\*b\*` 로 돌려준다    |
| `~~b~~` · `$x$`       | 취소선 · 인라인 수식          |
| `\~\~b\~\~` · `\$x\$` | 글자 — escape 그대로 돌려준다 |
| `<u>b</u>`            | 글자 — `\<u\>b\</u\>`         |

볼트에 없는 노트를 가리키는 위키링크는 글로 보낸다. 대상 · 별칭의 `* _ ~ ` $` 를 escape 해 보내고, 받을 때
위키링크 안의 `\* \_ \~ \` \$ \< \>`를 푼다.`\|`는 표 칸의 별칭 구분자라 둔다.`[[notion:<id>|…]]` 는 링크 글자라 뺀다.
라이브: 6 꼴 보내고 새 볼트로 받기 — 같음 · 다시 push 0.

### 표 칸의 별칭 위키링크 (실측 `__pipeprobe__`)

Notion 의 파이프 표는 `\|` 를 escape 로 읽지 않는다 — `p\|q` · `[[x\|y]]` · `[x\|y](주소)` 모두 그 자리에서 칸이
갈렸다. NFM 표 칸의 `[[x|y]]` 는 글자 그대로 두고 `\[\[x\|y\]\]` 로 돌려준다.

- 위키링크 대상 끝의 `\` 를 뗀다 — 노트 이름에는 `\` 를 쓸 수 없다
- 글로 남는 위키링크가 든 표는 NFM 표로 보낸다(칸 안 `\|` 가 든 표는 이미 그랬다, F-06)
- 받을 때 표 칸의 `[[notion:<id>\|별칭]]` 도 해소한다 — 같은 pull 에서 뒤에 받은 노트를 가리키는 링크

라이브: 볼트에 있는 노트 · 없는 노트 · 칸 안 파이프가 든 표 — 새 볼트로 받기 같음 · 다시 push 0.

## 남은 한계

- 블록 안 소프트 줄바꿈(홑 `\n`)은 블록 둘로 갈린다 — `<br>` 만 블록 안 줄바꿈이다
- 이미 Notion 에서 끊긴 링크 글자 · 갈린 표는 노트를 고쳐 다시 올려야 고쳐진다
- 예전 빌드가 노트 옆에 둔 행의 하위 페이지는 옮기지 않는다
- 새 볼트로 받은 폴더 노트는 본문에 없던 자식 링크가 끝에 붙는다
- 코드 언어 `js` 는 `javascript` 로 돌아온다
