# 개발 일지 — 2026-05-15

## 오늘 한 일

### Notion CLI 분석 + v0.1.3 개발 계획 수립

Notion이 2026-05-13에 공식 CLI(`ntn`)를 출시하면서,
Im-Nobsidian 프로젝트에 활용 가능한 신규 API/기능을 심층 분석.

### 핵심 발견: Im-Nobsidian은 이미 최적 구조

다른 AI의 분석에서 "martian/notion-to-md를 삭제하고 ntn으로 교체하라"는
제안이 있었으나, 코드 분석 결과 **근본적으로 틀린 분석**이었음:

1. **Im-Nobsidian은 이미 Markdown API를 PRIMARY로 사용 중**
   - `orchestrator.ts` line 888-901: `createPageWithMarkdown()` → Block API는 FALLBACK
   - `orchestrator.ts` line 946-956: `getPageMarkdown()` → notion-to-md는 FALLBACK
2. **File Upload API도 이미 3단계 구현 완료**
   - `client.ts` line 225-244: create → send → complete
3. **16개 프로세서는 Obsidian↔Enhanced Markdown 변환 레이어**
   - ntn을 써도 이 변환은 필수 — Notion API가 해주는 게 아님
4. **ntn은 같은 API의 CLI 래퍼일 뿐** — 코드에서 직접 SDK 호출하는 것과 동일

### Phase 1 개발 시작 — API 최신화

**Branch:** `feature/phase1-api-modernization`

#### 1A. `update_content` 부분 업데이트 (완료)

- **참고:** Notion SDK `pages.updateMarkdown()` 타입 정의
  - `type: "update_content"`, `content_updates: [{ old_str, new_str }]`
- **구현:** `client.ts` — `updatePageMarkdownPartial()` 메서드 추가
- **적용:** `orchestrator.ts` — `pushUpdatePage()`에서 baseSnapshot 기반 diff 계산
  - 변경이 적을 때 (≤20 패치) → 부분 업데이트
  - 대규모 변경 → 기존 `replace_content` 유지
- **효과:** Notion에서 다른 사람이 편집한 섹션 보존

#### 1B. Move page API (완료)

- **참고:** Notion API 2026-01-15 Move page 엔드포인트
- **구현:** `client.ts` — `movePage()` 메서드 추가
- **적용:** `orchestrator.ts` — `pushMove()` 메서드 분리
  - 기존: moved → pushUpdate() (내용만 업데이트, 위치 변경 없음)
  - 신규: moved → pushMove() (위치 이동 + 내용 업데이트)
- **효과:** 파일 이동 시 Notion 페이지 히스토리/코멘트 보존

#### 1C. 충돌 remoteContent 실제 조회 (완료)

- **문제:** `buildConflictsFromRecords()`에서 `remoteContent: ""` 하드코딩
- **수정:** `fetchPageMarkdown()` 호출하여 실제 원격 내용 조회
- **효과:** `nobsi diff`에서 local/remote 양쪽 비교 가능

## 결정 사항

| 결정                                | 이유                                            |

| ntn CLI 대신 SDK 직접 호출 유지     | ntn은 래퍼일 뿐, 프로세스 스폰 오버헤드 불필요  |
| `update_content` 부분 업데이트 도입 | 동시 편집 충돌 감소, Notion API 2026-03-11 신규 |

| 변환 레이어 유지                    | Enhanced MD ≠ Obsidian MD, 변환 필수            |
