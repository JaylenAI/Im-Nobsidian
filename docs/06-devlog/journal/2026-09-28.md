## N-04 — 새 페이지 · 행의 맨 앞 `# H1`

원인(실측, 2026-09-27 표): Notion 은 markdown 으로 페이지를 만들 때 맨 앞 `# H1` 을 버린다. push 는
새 노트를 그 요청 하나로 만들었다. 가운데 H1 · 맨 앞 `##` · 블록으로 만든 heading_1 · 본문
교체(`replace_content`)는 남는다. DB 행도 같다 — 프로브 DB `S03-자식-DB` 에 `# 행 맨 앞 H1` · 본문으로 만든 행이 문단만 남았다(`…6653`, 휴지통으로 옮김).

수정(`fix/leading-h1-create`, ADR-014): 만든 직후, 보낸 markdown 이 `# H1` 으로 시작할 때만 같은
markdown 으로 본문을 한 번 바꾼다. 매핑(pending · 해시 빈 값)을 먼저 적은 뒤, 첨부를 올리기 전에
부르고, 되살렸으면 수정 시각을 다시 받아 적는다. 실패하면 그 항목만 실패하고 다음 시도는 갱신이다.
페이지 · 자동 발견 DB 행(orchestrator)과 설정 DB 행(database-syncer) 세 생성 경로가 같다.

  줄바꿈이 없다. S-16 r2 와 같은 선존재 모양 — Phase 2 변환 왕복.
