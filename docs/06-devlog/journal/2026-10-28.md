## 조사 중 찾은 것

- **5 의 링크가 실 Notion 에서 깨졌다.** 블록을 모르는 서명 URL 은 페이지 주소만 갖는데, pull 후처리의 Notion 링크 복원
  (`link-restore`)이 그것을 `[[↗ Notion 에서 열기 · 1MB]]` 로 바꿨다. 그 노트를 push 하면 Notion 에 새 문단이 생겼다. 단위
  시험은 블록 주소(`#…`)가 붙은 꼴만 봐서 놓쳤다 — 후처리를 지나는 시험을 더했다
- pull 의 순서: Markdown API 변환 → 받기(`downloadAllFiles`) → **후처리 파이프라인**. 받기가 더한 글자는 후처리를 지난다
- 상한을 1KB 까지 낮출 수 있어 5KB 파일이 「1MB」 로 적혔다 — 1MB 아래는 KB
- 읽기 전용 속성: 사본에 볼트의 값이 남아 다음 pull 이 «우리가 쓴 그대로» 로 보고 받지 않았다. push 뒤 그 행을
  `markRemoteUnverified` 로 표시해 다음 pull 이 비교하게 했다
