## 4. 결함5 — 본문 `---` 시작 시 frontmatter 유실 (#49) ⭐

fresh-user E2E pull(247개 복잡 페이지) 중 발견한 **무손실 위반(I2)**.

### 근본 원인

gray-matter `matter.stringify(string, data)`는 첫 인자가 문자열이면 내부에서
`matter(file)`로 본문을 재파싱한다. Notion divider 등으로 본문이 `---`로 시작하면
그 `---…---` 블록을 frontmatter로 오인해 YAML 파싱하다 throw:

```
[FrontmatterGenerator] Post-processor failed: YAMLException: unidentified alias "*돌아보기**"
[FrontmatterGenerator] Post-processor failed: YAMLException: end of the stream ... [🔗 Embed](...)
```

`pipeline.ts`의 try/catch가 throw를 삼켜 post-processor 전체가 스킵 → **그 파일의
속성이 통째로 누락**되는 조용한 데이터 유실.

### 수정

`packages/core/src/utils/frontmatter.ts`에 `stringifyFrontmatter()` 헬퍼 추가 —
`matter.stringify({ content }, data)` 객체 형태로 호출해 재파싱 자체를 차단. 동일
패턴 호출처 3곳 전부 교체:

| 파일                                 | 상태                 |
| ------------------------------------ | -------------------- |
| `frontmatter-generator.ts`           | 실제 버그            |
| `view/entry-editor.ts`               | 동일 잠재버그        |
| `pre-processors/properties-table.ts` | 안전했으나 패턴 통일 |

회귀 테스트 1건 추가. 커밋 5e2b8e8(feature/db-base-fidelity).

  종료코드로 성패를 신뢰 가능.
